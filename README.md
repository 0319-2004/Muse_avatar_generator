# アバタープロンプト生成ツール

GPT Image などでアバター画像を作るための、画像生成プロンプトを作るツールです。
スタイルやキャラの特徴をチップで選ぶと、GPT Image 向けのプロンプトがその場で組み上がります。

## 使い方

1. `index.html` をブラウザで開く（サーバー不要・単一ファイル）
2. スタイル（3Dフィギュア風、ピクサー風、クレイモデル風、ドット絵風など全6種）と、キャラの特徴・髪型・服装・表情・小物・色味を選ぶ
3. 生成されたプロンプトをコピーして GPT Image などに貼り、画像を作る
4. できた画像を Muse に渡すと、アバター候補にしてもらえる（ツール内の依頼文をそのまま使えます）

日本語 / English の切り替え付き。プロンプトには「正面・顔アップ・背景シンプル」が自動で付きます。

## 公開する

GitHub Pages で公開する場合：

1. 新しいリポジトリを作る（例：`avatar-prompt-generator`）
2. このフォルダの `abatapuronputosheng-cheng-turu.html` を `index.html` にリネームしてアップロード
3. Settings → Pages → 「Deploy from a branch」を選ぶと URL で見られるようになります

## 注意

- 画像生成そのものはこのツールでは行いません。プロンプト生成が役割です。
- 実在の人物の顔を混ぜた画像を作る場合は、公開・共有する前に肖像権などの扱いに注意してください。
